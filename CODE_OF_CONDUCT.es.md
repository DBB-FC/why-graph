# Código de conducta

*Español · [Read in English](CODE_OF_CONDUCT.md)*

Why Graph es un proyecto pequeño que se construye a la vista, y quienes lo usan vienen de muchos
lugares y hablan distintos idiomas. El español y el inglés son bienvenidos en todo este repositorio.

## Qué esperamos

- Sé amable y asume buena intención. Casi todos los errores los reporta alguien que acaba de perder tiempo.
- Critica el código, el diseño o la idea, nunca a la persona.
- Comparte lo que sabes. Un reporte claro o un vault con el que se pueda reproducir el error es un regalo.
- Respeta las notas ajenas: nunca pegues contenido privado de tu vault ni del de otra persona.

## Qué no se acepta

Acoso, insultos, ataques personales o políticos, lenguaje o imágenes sexualizadas, publicar
información privada de alguien y cualquier conducta que estaría fuera de lugar en un entorno profesional.

## Cómo se aplica

Quien mantiene el proyecto puede editar o borrar comentarios, issues y pull requests que rompan
estas reglas, y bloquear a quien las rompa de forma reiterada. Para reportar algo en privado, escribe
a **hola@dontbuybuild.cl**. Los reportes los lee solo quien mantiene el proyecto y son confidenciales.

Este código está adaptado del [Contributor Covenant](https://www.contributor-covenant.org/),
versión 2.1.
